# Phase 3 规则型归因

最后更新：2026-08-09

## 状态与范围

Phase 3 已执行并通过验证。它仅在最终 Phase 2B `conversion_touchpoints` 输入上实现首次点击、末次点击、末次非直接点击、线性和七天时间衰减。未创建 Markov、非转化路径、敏感性、自助法、Shapley、预算或仪表板输出。

这是对公开混淆 GA4 电商样本的描述性归因。结果不代表 Google Merchandise Store 的实际表现，也不能证明因果增量。

## 验证

全部 70 项 Phase 2B 前置检查及 46 项 Phase 3 检查通过。Phase 3 验证确认了输入版本与总体、公式的精确复现、规范粒度唯一性、五模型覆盖、每订单和每模型的转化及收入核对、全直接访问回退、排除项核对、渠道比较核对、转化后触点为零、Internal/Admin 输出行为零，以及不存在后续阶段表。

本地验证通过 52 项 pytest 测试，其中包括 14 项 Phase 3 runner 测试。`git diff --check` 通过。现有虚拟环境和系统环境均没有 Ruff，因此未安装。

## 局限与停止门

- 归因是描述性的，不是因果性的。
- 基准使用固定的七天时间衰减半衰期；Phase 3 不评估其他半衰期。
- 重复 Session 和渠道均保留，不做压缩。
- 未知来源证据仍是独立渠道。
- 经批准移除 Internal/Admin 后仍有 9 笔订单不可归因。

Phase 3 到此停止。Markov 及所有后续阶段工作均需另行批准。
