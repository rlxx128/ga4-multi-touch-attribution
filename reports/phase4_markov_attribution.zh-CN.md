## 移除规则的决策历史

首先执行并否决了前驱—后继重连规则。该规则从每条路径删除渠道出现、重连剩余状态，并保留每条旅程原有的 Conversion 或 Null 终点。这样会使基准吸收概率在删除后保持不变：总移除效应为 `2.886579864025407e-15`，在 `1e-12` 容差下属于数值零。规范化门正确地没有创建任何表。

最终批准的 Anderl 风格规则从原始基准图中移除一个渠道状态。对于渠道 `C`，每个剩余行都把原来的 `i -> C` 概率重定向至 Null：

```text
P_removed(i, Null) = P_baseline(i, Null) + P_baseline(i, C)
P_removed(i, j) = P_baseline(i, j), for j != C and j != Null
```

删除 `C` 的行和列；其他概率不重新归一化；Conversion 和 Null 保持吸收状态；每次渠道移除都独立地从同一个基准矩阵开始。解释是：下一步原本进入被移除渠道的概率质量变为不转化；不对现实渠道替代建模。

## 局限性

- 右删失排除了 91,594 条候选旅程。
- 保留的 77,918 条左边界 Null 旅程没有完整的窗口前历史。
- 把进入渠道的概率重定向至 Null 假设不存在其他渠道替代；存在替代时可能高估依赖。
- 一阶聚合会丢失高阶路径上下文。
- 全局份额向量使转化份额与收入份额相同。
- `Unknown` 是未解决的来源数据，不是可直接行动的预算渠道。
- Markov 归因表示结构性路径贡献，不是因果效应、增量提升、真实收入损失、现实销售损失、实际最优预算或现实渠道替代。
